# Rights and release status

The release maintainer confirmed authority to publish the original code and documentation under the MIT license and to redistribute the included derived statistics and frozen aggregates. The MIT terms apply to the original code and documentation. Authorship follows the final manuscript.

The package uses externally installed dependencies. The installed wheel metadata identify BSD terms for pandas and SciPy, multiple notice terms for bundled NumPy components, BSD/Apache for python-dateutil, MIT for six and pytz, and Apache-2.0 for tzdata. Their code and wheels are excluded from the archive. These terms do not select a licence for the IA code or documentation.

The archive includes gene-level summary statistics and aggregate outputs. Existing source terms continue to apply to underlying datasets. The archive excludes controlled observations, bulk specimen matrices, cell matrices and third-party article text. [NCBI GEO disclaimer](https://www.ncbi.nlm.nih.gov/geo/info/disclaimer.html), [Wang et al. source paper](https://doi.org/10.1038/s41593-026-02326-9).

Authorship, the dated version, and input hashes make the work traceable. They do not grant exclusive rights over scientific questions or independent findings.
