# Environment

The frozen Q1 dependency receipt records CPython 3.13.11, NumPy 2.5.3, pandas 2.3.3 and SciPy 1.18.1. The standalone package uses those versions and locks the transitive dependencies in `requirements.txt`. Validation used a fresh isolated CPython 3.13.11 environment on macOS arm64, installed offline from locally cached registry wheels after the network request to PyPI failed. Registry installation and other operating systems were outside the validation. No R, workbook software, credentials, source project directories or network calls are needed at run time.

Matching uses the original NumPy argpartition, including its ordering within the selected 200. The historical draw stream indexes that order. Fig. 3 Welch vectors use round-trip decimal parsing to preserve ties and ranks. The runner tests Q1 against frozen four-decimal claim values, the archived aggregate rounding and the exact Monte Carlo tail count. The CIs are from deterministic replay of a fixed stream, and represent uncertainty in the analysis. For D1 use absolute tolerance 5e-10 against archived statistics printed to ten significant digits. The Figure 1E correlation and agreement fraction are deterministic. Absolute tolerance 1e-12 allows floating-point reduction differences against the full-precision frozen summary.
