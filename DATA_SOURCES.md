GEO and atlas links below identify the upstream studies for attribution and retrieval. Downloading those upstream records alone will not produce the documented intermediate datasets.

## Figure 2

- `q1/claims.tsv` projects the frozen testable Q1 frame and r̄ ≥ 0.3 co-expression cluster assignments. It carries approved HGNC identity, direction and the frozen measured, source-exposed and used cohorts. Raw literature extraction, author exposure adjudication and estimation of the co-expression clusters occur upstream. The 239 IDs, effects, directions, cohorts and clusters were reconciled against the revised S1.
- `q1/BG_*.tsv.gz` are projections of the hash-verified Oct 24 R2.1 contrast backgrounds generated by `r2_11_cohort_effects_lit.py` with `ia_data.py`. The loader reads the frozen public cohort processed scales, applies platform mapping and cohort/sample rules, and calculates case-minus-reference Hedges’ g and its variance. Expression and SD percentile ranks are computed over the contrast samples. `xl_common.load_backgrounds` preserves the first occurrence of each HGNC ID. The projections preserve row order and all eligible comparator rows from used contrasts. They contain gene-level summaries and no specimen columns.
- At run time the matcher intersects HGNC IDs across the eligible unexposed cohorts. It takes the 200 nearest genes by Euclidean distance in the first sorted eligible cohort's two percentile ranks, excludes the claim gene, pools effects by DerSimonian–Laird and signs them by the claim direction. The independent-draw null replaces each claim with a matched gene and ranks it against the remaining controls plus the original claim. The cluster bootstrap instead resamples frozen clusters and recentres the within-pool excess at 0.5.
- `q1/frozen_claim_results.tsv`, `q1_label_draws.tsv` and `strict58_outcomes.tsv` are separate frozen references. The label draws were produced upstream by joint phenotype permutations and are used only to check the reported tail. The strict set is publication-specific and uses different inclusion rules.

## Figure 3 and the IA GSE54083 input

- `rupture_welch.tsv.gz` holds eight gene-wise Welch t vectors on the sorted 15,648-gene intersection, computed from the frozen D1 cohort bundle after the verified GSE54083 override. `rupture_counts.tsv` carries cohort-level counts. D1 intersects genes with finite contrasts before computing rank-inverse-normal scores and fitting the lesion factor.
- Both frozen Q1 and D1 preparation used the same corrected ordinal-feature input (SHA-256 `e1e9b30548c9c0ef0dc0aab766da6c918fa14452f354915fc3cb74519f2e122b`). The IA study reconstructed the feature-record ordinal after omitting 205 probe-less controls from the deposited raw Agilent files, then used the repaired probe-to-gene assignments. The Q1 input came through the hash-pinned repaired-only loader. D1 replaced the legacy cache matrix, checked its hash and checked sample order before computing any contrast. The standalone workflow starts after those steps. It validates the resulting prepared-input hashes and has no GEO default-annotation code path.
- `rupture_draws.tsv.gz` contains only the Dbar statistic from the frozen M1 simulation and Bayesian bootstrap streams, main and leave-one-rupture-cohort-out. The latter drops three rupture pairs and preserves the original lesion fit. `rupture_frozen.tsv` holds publication references, including the STA-only summary for context. The runner recalculates intervals and tails only for the main and GSE54083 rupture-pair sensitivity. Fig. 3B programme results are frozen aggregate rows.

## Optional Figure 6A input

```sh
python -m scripts.reproduce_smc_simulation /path/to/smc_prepared.npz
```

The executable requires the exact author-prepared NPZ specified by `expected/smc.json`. For this internal candidate, the validated file is supplied separately to the authors in the QA folder. A reader of a future public archive would need the same file from the authors subject to authorization. There is no public endpoint for that prepared input and no public-download replay is claimed. Use the bundled aggregate check when the input is unavailable.

The original E01 preparation maps GSE122897 counts to gene symbols, sums duplicate symbols, keeps the 21 UIA specimens and generates TPM using the model gene universe and lengths. The Wang atlas donor pseudobulks use the frozen E01 donor convention, ≥20 SMCs for eligible profiles, and the original six class means and 300 NNLS markers. The optional package retains length-weighted baseline values on the 300 markers, full gene-universe library sums, the six-column NNLS reference, the original source-profile SMC attribution on markers and weighted totals for exact CPM closure. The state multiplier uses the full-dose E01 target/source pseudobulk ratio with pseudocount 10 and per-gene source SMC attribution. Weighted NNLS retains the CPM + 0.5 pseudocount and normalized coefficients. The included check covers all six same-assay scRNA control-to-UIA worlds and the first matchable same-assay scRNA control swap by frozen pair ID. It does not fit new atlases or classifiers. Specimen-derived arrays remain outside Git and the proposed deposit.

## Other verification inputs

Fig. 1 gene counts, study reuse, model class rows and annotation effects, Fig. 4 score labels and transport verdicts, Fig. 5D bounds with donor labels removed, S5 atlas class counts and Fig. 6 world readings/AUROCs are projections of frozen manuscript Source Data or tables. They support Level C checks. The Fig. 1D projection applies the November 7 MLDGS correction to `PERIPHERAL_BLOOD` and `missing`. The original full Source Data table still requires the author-side correction. Neither the submission workbooks, PDFs nor large third-party files are included.
